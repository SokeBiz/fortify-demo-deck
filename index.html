03 / How it works
Separation of powers

The agent plans.
The evidence decides.

The AI agent is useful for judgment, not truth. It cannot prove an exploit by itself, and it cannot silently widen the scope.

AI agent

Plans and triages

Reads the repository, picks checks, groups duplicates, explains risk in plain language.

Deterministic tools

Produce the evidence

Gitleaks, Semgrep, Trivy, OWASP ZAP, and custom attack probes run against a disposable copy.

Proof gate

Promotes only what works

No reproducible request and response, no proven finding. Fixes are replayed to verify.

Guardrails: narrow scope, no repo writes, full audit.04
